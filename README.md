# E-E-A-T Signals

A plain-language reference on E-E-A-T: experience, expertise, authoritativeness, and trustworthiness, the qualities search and AI systems use to judge whether content deserves to rank and be cited. It covers what each letter means, the concrete signals that demonstrate them, why trust is the foundation, and how a small operator can show E-E-A-T honestly.

## The core idea

E-E-A-T stands for experience, expertise, authoritativeness, and trustworthiness. It is a framework for the qualities that make content worth trusting, used to judge whether content should rank and be cited. You demonstrate E-E-A-T through concrete signals: showing real firsthand experience, real qualifications, recognition from others, and the honesty markers that establish trust. A small operator can show all four genuinely, without faking authority.

## The stance

This reference treats E-E-A-T as something you demonstrate by being genuinely experienced, knowledgeable, recognized, and honest, then making those facts visible. It is not a trick to fake; it is a set of real qualities to show clearly.
